# Hogar Raíces de Amor — sitio web inicial

Sitio estático adaptable a móviles, en español y sin dependencias externas.

## Cómo abrirlo
1. Extraé el ZIP completo en una carpeta.
2. Abrí `index.html` con Chrome o Firefox.
3. Para editar, podés usar Visual Studio Code, pero no es obligatorio.

Cada archivo HTML incluye sus propios estilos, scripts, ilustraciones y favicon, así que puede abrirse por separado sin servidor ni conexión a internet. `index.html` es la portada y cada sección del sitio tiene su propio archivo; la navegación conecta las páginas entre sí.

## Antes de publicar
- Reemplazá los textos de ejemplo por información verificada del hogar.
- Agregá fotos propias con autorización y optimizadas para web.
- Confirmá teléfono, correo, dirección, tarifas y políticas reales.
- Actualizá `robots.txt` y `sitemap.xml` con el dominio final.
- El formulario prepara un correo y no transmite datos a un servidor. Configurá un canal de contacto real antes de publicar.
- Revisá el aviso de privacidad con la persona responsable.

## Archivos fuente
Los estilos, scripts e ilustraciones originales se conservan en `assets/` para facilitar su edición. Los archivos HTML ya contienen copias integradas de esos recursos y funcionan de manera independiente.
